# 小爱记账

**不用联网、不用登录、不用注册 —— 双击就能用的个人记账本。**

一个单文件的 Windows 桌面记账程序：启动后在浏览器里打开界面，数据存在程序目录下的 JSON 文件里，全程本地、不联网、不上传。

## 功能

- **记账**：支出 / 收入，一级 + 二级分类，备注，自定义图标
- **账单**：按月份、类型、分类筛选，关键词搜索，范围筛选，分页
- **统计**：分类占比、月度趋势、收支对比、日均支出
- **预算**：每月预算、跨月结转（上月超支自动扣减）、可关闭某月或从某月起不再设置
- **分期与循环账单**：信用卡分期、房租水电等固定账单，自动计算待还与下次到期
- **回收站**：删除的记录先进回收站，可单条或批量恢复
- **备份**：手动备份、导出备份包、从备份文件恢复、升级前自动备份
- **导入导出**：Excel / TXT / JSON，按月份范围导出
- **理财盈亏**：填账户当前市值，自动算成本 / 浮盈亏 / 收益率（市值快照不进收支）
- **资产筛选**：账单页可只看存款、只看总资产（含市值快照）
- **统计口径开关**：可选是否把「理财存入」算进饼图与支出
- **一键升级**：用升级包替换程序文件，账本数据原样保留

## 快速开始

1. 到 [Releases 页面](https://github.com/feng20010612-glitch/xiaoai-ledger/releases) 下载 `xiaoai-ledger-v2.15.27.exe`（约 30 MB）
2. 放到一个固定文件夹（例如 `D:\小爱记账\`），双击运行
3. 浏览器会自动打开 `http://127.0.0.1:8899/`，这就是记账界面

数据会保存在程序目录的 `data/` 下（就是几个 JSON 文件），想换电脑直接整个文件夹拷走即可。

## 从源码运行

```bash
python 小爱记账.py
```

只需要 Python 3.9+ 标准库，没有第三方依赖。

打包成单文件 exe：

```bash
pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --name 小爱记账 --icon icon.ico --noconsole 小爱记账.py
```

## 目录结构

```
小爱记账.py          后端（HTTP 服务 + 数据读写）
记账本-v2.html       前端单页（原生 JS，无框架）
chart.umd.min.js     图表库
icon.ico             程序图标
更新日志.md          版本历史
使用手册.md          完整使用说明
data/                账本数据（首次运行自动创建）
```

## 数据与隐私

- 所有数据只存在本机 `data/` 目录，**不联网、不上传、无账号**
- 删除有回收站，升级前自动备份，备份可导出成 zip
- 端口默认 `8899`，只监听本机；多份账本可在各自目录放 `port.txt` 指定不同端口
